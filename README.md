# Customer Contact Management System

A simple 3-tier desktop application for managing customer contacts.

### 8. Permanent Storage
Store data permanently using relational database (SQLite) - customer.db

### 9. Easy GUI
Provide easy-to-use graphical interface for non-technical users using Tkinter.

### Technologies Used
- Python 3.x - Core programming language
- Tkinter - GUI frontend
- SQLite - Lightweight database
- SQL - Querying data
- VS Code - IDE
